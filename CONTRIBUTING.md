# Contribuindo / Contributing

[Português](#português) · [English](#english)

## Português

Obrigado por querer ajudar! Qualquer contribuição é bem-vinda: correções de tradução, novos dados, melhorias no site ou correção de bugs.

### Passo a passo

1. **Faça um fork** do repositório (ou clone-o diretamente, se você for colaborador com acesso de escrita).
2. **Clone** o repositório na sua máquina:
   ```bash
   git clone git@github.com:<seu-usuario>/fire-emblem-fw-portuguese-db.git
   cd fire-emblem-fw-portuguese-db
   npm install
   ```
3. **Atualize a `main`** e **crie uma nova branch** a partir dela. Nunca trabalhe direto na `main`:
   ```bash
   git checkout main
   git pull origin main
   git checkout -b tipo/descricao-curta
   ```
   Exemplos de nome: `traducao/corrige-skills-pt-pt`, `feature/pagina-de-classes`, `fix/tabela-recrutamento`.
4. **Faça suas alterações** e teste localmente:
   ```bash
   npm run dev      # abre o site para testar
   npm run build    # precisa passar sem erros
   ```
5. **Faça o commit** com uma mensagem clara e curta:
   ```bash
   git add <arquivos>
   git commit -m "Corrige descrição da habilidade Soar em pt-PT"
   ```
6. **Envie a branch** para o GitHub:
   ```bash
   git push -u origin tipo/descricao-curta
   ```
7. **Abra um Pull Request** para a `main` pelo GitHub. Descreva o que mudou e por quê; se mexeu na interface, anexe um print.
8. Aguarde a revisão. Se pedirem ajustes, faça novos commits na mesma branch e dê `git push` — o PR é atualizado automaticamente.

### Dicas

- **Um assunto por PR.** PRs pequenos são revisados mais rápido.
- **Idiomas:** apenas o `README.md` e o texto do site são em português. Nomes de personagens e de habilidades ficam sempre em inglês. Os demais arquivos de documentação ficam em inglês (este arquivo é a exceção, por ser bilíngue).
- **Traduções:** as descrições das habilidades ficam em `src/i18n/skills.pt-BR.json`. Para pt-PT, adicione apenas as diferenças em `src/i18n/skills.pt-PT.json`. Os textos da interface ficam em `src/i18n/ui.ts`.
- **Dados:** `src/data/*.json` são gerados por `npm run data`; prefira alterar o script `scripts/build-data.mjs` a editar esses arquivos à mão.
- Detalhes técnicos em [TECH_STACK.md](TECH_STACK.md).
- Depois que o PR for aceito na `main`, o site é publicado automaticamente pelo GitHub Actions.

## English

Thanks for wanting to help! All contributions are welcome: translation fixes, new data, site improvements or bug fixes.

### Step by step

1. **Fork** the repository (or clone it directly if you are a collaborator with write access).
2. **Clone** it to your machine:
   ```bash
   git clone git@github.com:<your-username>/fire-emblem-fw-portuguese-db.git
   cd fire-emblem-fw-portuguese-db
   npm install
   ```
3. **Update `main`** and **create a new branch** from it. Never work directly on `main`:
   ```bash
   git checkout main
   git pull origin main
   git checkout -b type/short-description
   ```
   Example names: `translation/fix-skills-pt-pt`, `feature/classes-page`, `fix/recruitment-table`.
4. **Make your changes** and test locally:
   ```bash
   npm run dev      # opens the site for testing
   npm run build    # must pass without errors
   ```
5. **Commit** with a short, clear message:
   ```bash
   git add <files>
   git commit -m "Fix Soar skill description in pt-PT"
   ```
6. **Push** the branch to GitHub:
   ```bash
   git push -u origin type/short-description
   ```
7. **Open a Pull Request** against `main` on GitHub. Describe what changed and why; if you touched the UI, attach a screenshot.
8. Wait for review. If changes are requested, add new commits to the same branch and `git push` — the PR updates automatically.

### Tips

- **One topic per PR.** Small PRs get reviewed faster.
- **Languages:** only `README.md` and the site text are in Portuguese. Character and skill names always stay in English. Other documentation files are in English (this file is the exception, being bilingual).
- **Translations:** skill descriptions live in `src/i18n/skills.pt-BR.json`. For pt-PT, add only the differences to `src/i18n/skills.pt-PT.json`. UI strings live in `src/i18n/ui.ts`.
- **Data:** `src/data/*.json` is generated by `npm run data`; prefer changing `scripts/build-data.mjs` over hand-editing those files.
- Technical details in [TECH_STACK.md](TECH_STACK.md).
- Once a PR is merged into `main`, the site is published automatically by GitHub Actions.
